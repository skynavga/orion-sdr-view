#     --script scripts/cofdm-continuous.txt --dump run.jsonl
#
# Why it matters for a measurement: a gap resets the receiver and restarts its
# frame accounting, so a run that outlasted the burst would report only the
# frames after the last gap — with nothing in the dump to say so except an
# `instrumentcleared` record.  `tests/cofdm_link_budget.rs` uses exactly this
# configuration, and asserts that no such record appears.
