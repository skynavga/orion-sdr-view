# Zoom, lock and pan — a UI reproduction recipe rather than a measurement.
#
# `assert` directives are the point of this one.  The driver parses them, so a
# typo is still an error, and then ignores them; the test harness in `tests/`
# executes them.  One format, two readers: drop this file into a test and it
# becomes a regression test unchanged.
#
# The zoom here is for the lock, not for the pan: a *locked* pan is held inside
# the band, and at full span that leaves it nowhere to go.  An unlocked pan
# needs no such preparation — see `overscan.txt`.

set run.duration 8

0.00 source COFDM
1.00 key ArrowUp x3        # zoom in
2.00 assert source COFDM
2.00 key L                 # lock the band to the viewport centre
2.50 assert locked 1
3.00 key ArrowRight x4     # pan up-band; the band follows
4.00 key shift+ArrowRight  # fine pan, 10% of coarse
5.00 key Z                 # re-centre, keeping the zoom
